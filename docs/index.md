## What the platform refuses to do

- **Classify content.** No pornographic / medical / educational / artistic judgement. That boundary
  does not survive contact with a well-lit anatomical photograph. The platform describes, and lets
  viewers choose.
- **Assume a default body.** Anatomy is a set of features, not a type with variants. Intersex, trans
  and post-surgical bodies need no special case because there is no default case.
- **Show a figure without its uncertainty.** A number without a sample size and an interval is a
  claim the platform will not make.
- **Present group differences as facts about racial categories.** Population comparison is framed by
  region and study cohort, with the evolutionary and regional mechanism stated.
- **Rank people.** No leaderboards, no scores, no streaks, no engagement notifications.
- **Exempt operators.** Privileged access is scoped, justified, externally audited and bounded.
